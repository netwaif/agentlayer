# 스킬 초안 — `handoff` (앱 간 넘기기), 사용자 확정 전

대상: 데스크톱 앱(Claude Code)만 쓰는 초보. 설치·실행 전부 앱 안에서. tmux·훅·총괄·AI 회사 전제 없음.
배포: folder-bot처럼 별도 플러그인 마켓플레이스(예: `netwaif/handoff`). 앱의 Claude Code에서 `/plugin marketplace add …` → `/plugin install handoff`.
바이너리: 스킬이 첫 실행에 `agentlayer` 유무를 확인하고 없으면 `brew install netwaif/tap/agentlayer`(1.12.0+)를 앱 안 Bash로 실행.

## SKILL.md (초안)

```markdown
---
name: handoff
description: 지금 이 Claude 세션에서 다른 앱의 에이전트에게 일을 넘기고 답을 받는다. "코덱스에 (이미지 만들어 달라고) 시켜", "이거 코덱스로 넘겨", "헤르메스에게 이 파일(스킬) 보내", "메시지 받을 준비해", "/handoff" 에 사용. 터미널 없이 데스크톱 앱 안에서만 쓴다.
---

# 다른 앱으로 넘기기

준비(한 번): `agentlayer version`이 1.12.0 이상인지 본다. 없거나 낮으면 `brew install netwaif/tap/agentlayer`(없으면 `brew upgrade`)를 실행하고 다시 확인한다.

## 입구 1 — "코덱스에 시켜"
1. 내 이름을 정한다: 폴더명(예 `blog`). 사용자가 이름을 말했으면 그것.
2. 코덱스 세션 ID를 확보한다. 사용자가 이번 대화에서 알려 준 UUID가 있으면 그것, 없으면 한 번만 묻는다("코덱스 앱에서 '세션 번호 알려줘'라고 물어 나온 ID를 붙여 주세요").
3. 먼저 답 받을 준비를 켠다(백그라운드 Bash):
   `agentlayer inbox wait --name <내이름> --timeout 30m`
4. 요청을 보낸다(플래그는 대상 앞에):
   `agentlayer send --json --cwd <작업폴더> <코덱스 세션 ID> "<요청 본문>

   결과(파일 경로 포함)는 셸에서 다음 한 줄로 회신하라: agentlayer send <내이름> \"<결과 요약과 경로>\"
   30분 안에 회신하라."`
5. 백그라운드 명령이 끝나면 출력의 `from:` 다음 본문이 답이다. 파일 경로가 있으면 열어 확인하고 사용자에게 보고한다. `답 없음(30m)`으로 끝났으면 사용자에게 알리고, 계속 기다릴지 묻는다(기다리면 3을 다시 켠다).

## 입구 2 — "헤르메스에게 보내"
1. 등록된 원격 이름을 확인한다: `agentlayer remote list`. 하나면 그것, 여럿이면 묻는다. 없으면 이 스킬 범위 밖이라고 말한다(등록은 agentlayer 매뉴얼).
2. 파일이 있으면 `--file`을 파일마다 붙인다(폴더는 안 됨 — 필요하면 zip으로 묶어 하나로).
   `agentlayer send --json --file <경로> hermes-qa "<본문>

   받았으면 네 디스코드 채널에 '수신 확인 — <첫 줄 요약>' 한 줄을 올리고, 다른 작업은 하지 말고 끝내."`
3. 출력의 `handle`·`task_id`·`files`(원격 경로)를 사용자에게 보고한다. 디스코드 채널에 올라오는지는 사용자가 확인한다.

## 입구 3 — "메시지 받을 준비해"
`agentlayer inbox wait --name <내이름> --timeout 30m`을 백그라운드 Bash로 켜고, 보내는 쪽에 알려 줄 주소를 말한다: "`agentlayer send <내이름> \"…\"`로 보내면 됩니다". 편지가 오면 본문을 그대로 사용자에게 보이고 처리한다.

## 규칙
- 플래그(`--json`·`--file`·`--cwd`)는 반드시 대상 이름 앞에 쓴다. 뒤에 쓰면 본문으로 들어간다.
- 답을 기다리는 동안만 `inbox wait`를 켠다. 답이 오거나 시간이 지나면 끝난다. 상시로 켜 두지 않는다.
- 같은 이름의 tmux 세션이 있으면 그쪽이 우선이다(관제탑 사용자용 규칙). 초보 환경에는 해당 없음.
```

## 확정 전 결정 사항
1. 플러그인 이름·레포(`netwaif/handoff`?)와 마켓플레이스 등록 방식.
2. 코덱스 세션 ID를 매번 묻는 대신 저장할지(폴더별 `.handoff.json` 등). 초안은 "이번 대화에서 알려 준 것만".
3. 헤르메스 원격 등록(`remote add`)은 초보 범위에서 빼고 "있으면" 절로 두는지.
