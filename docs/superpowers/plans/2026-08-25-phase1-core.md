# AgentLayer Phase 1 — 관제 코어 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** tmux 전체의 에이전트 상태(WORKING/WAITING/DONE_UNREAD/…)를 파일 상태 저장소에 수집하고, `agentlayer status` CLI와 bubbletea TUI(목록·pane 점프·읽음 처리·`C-b a` 팝업)로 보여주는 단독 동작 코어를 만든다.

**Architecture:** 데몬 없는 파일 상태 저장소(`~/.local/state/agentlayer/agents/*.json`, temp→rename 원자적 쓰기). 상태 기록은 두 경로 — ① Claude Code hook이 `agentlayer hook claude` 서브커맨드로 이벤트를 밀어 넣고, ② TUI/CLI가 뜰 때마다 tmux pane 스캐너가 레코드를 현실과 동기화(신규 발견, 사라진 pane→DEAD). 화면 스크래핑으로 상태를 판정하지 않는다.

**Tech Stack:** Go 1.25, bubbletea v1 + lipgloss v1 (mat과 동일), 표준 라이브러리 위주. 모듈 경로 `github.com/netwaif/agentlayer`.

**Spec:** `docs/superpowers/specs/2026-08-25-agentlayer-design.md`

## Global Constraints

- 기존 tmux prefix·단축키를 변경하지 않는다. `C-b a`는 검증된 빈 키이며 사용자 옵트인(init)으로만 바인딩한다.
- 기존 tmux 세션·window·pane을 절대 kill하지 않는다.
- 상태 판정은 hook + 프로세스/pane 신호만. pane 화면 텍스트 스크래핑 금지.
- DONE_UNREAD → IDLE 전환은 사용자 행동(점프/읽음 키)으로만 일어난다.
- 상태 파일·로그에 인증정보(토큰·웹훅 URL 값 등)를 쓰지 않는다.
- 모든 파일 쓰기는 temp→rename 원자적 쓰기.
- tmux 의존 테스트는 임시 소켓(`tmux -L agentlayer-test-<pid>`)으로 기존 서버와 격리하고 테스트 종료 시 `kill-server`.
- 사용자 홈의 실제 상태 디렉터리를 테스트에서 건드리지 않는다(`t.TempDir()` + env 오버라이드 `AGENTLAYER_STATE_DIR`).

### Task 1: 프로젝트 스캐폴드 + 상태 타입

**Files:**
- Create: `go.mod`, `main.go`(최소), `internal/state/types.go`, `internal/state/types_test.go`

**Interfaces:**
- Produces:
  - `type AgentState string` — 상수 `StateWorking("WORKING")`, `StateWaiting("WAITING")`, `StateDoneUnread("DONE_UNREAD")`, `StateIdle("IDLE")`, `StateError("ERROR")`, `StateDead("DEAD")`
  - `type TmuxRef struct { Session string; Window int; PaneID string }` (PaneID는 `%3` 형식)
  - `type Agent struct { ID, Kind, Task string; State AgentState; Tmux TmuxRef; CWD, SessionID string; PID int; UpdatedAt, StateSince time.Time }` (JSON 태그 snake_case)
  - `func (s AgentState) Priority() int` — 정렬용: WAITING(0) < DONE_UNREAD(1) < ERROR(2) < WORKING(3) < IDLE(4) < DEAD(5)
  - `func (a *Agent) Transition(to AgentState, now time.Time)` — State 변경 + StateSince/UpdatedAt 갱신, 같은 상태면 UpdatedAt만
  - `func (a *Agent) Stale(now time.Time) bool` — WORKING이고 UpdatedAt이 30분 이상 과거면 true

- [ ] **Step 1:** `go mod init github.com/netwaif/agentlayer` + 빈 `main.go` + `go build ./...` 통과 확인
- [ ] **Step 2:** `types_test.go` 작성 — Transition이 StateSince를 갱신하는지/같은 상태 재진입 시 유지하는지, Priority 순서, Stale 경계(29분 false·31분 true), JSON round-trip
- [ ] **Step 3:** 테스트 실패 확인 (`go test ./internal/state/`)
- [ ] **Step 4:** `types.go` 구현, 테스트 통과
- [ ] **Step 5:** Commit `feat(state): Agent 레코드와 상태 전이 규칙`
