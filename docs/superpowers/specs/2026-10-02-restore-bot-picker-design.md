# restore 체크리스트에서 폴더 봇 골라 띄우기 — 설계

2026-10-02. 컴퓨터를 켜면 폴더 봇이 전부 자동으로 뜬다. 안 쓰는 봇까지 떠 있다. 매일 치는 `agentlayer restore`의 체크리스트에서 그날 쓸 봇만 골라 띄우게 한다. 기존 동작 불변(추가만).

## 전제 (바꾸지 않는 것)
- 대상은 **엔진을 가리지 않는 모든 봇**이다 — Claude 폴더 봇, 코덱스·agy 브리지 봇 전부.
- 봇을 자동으로 띄울지는 각 하네스의 설정이 정한다. agentlayer는 "자동 기동이 꺼져 있고 지금 안 떠 있는 봇"을 찾아 띄우기만 한다. 자동 기동이 꺼진 봇은 두 모양이다.
  - **(A) 사이드카형**: folder-bot이 구동 유닛을 지우고 기동 명령을 `~/.config/folder-bot/<세션>.tmux-cmd`(한 줄 셸 명령)에 남긴 봇. `bot-restart`가 이 파일로 `tmux new-session -d -s <세션> <명령>`을 한다.
  - **(B) 유닛형**: 구동 유닛(plist·systemd)은 남아 있되 자동 기동만 꺼진 봇 — macOS는 plist의 `RunAtLoad`가 false, 리눅스는 유닛이 disabled. 폴더 봇의 plist와 브리지 봇의 유닛(데몬 + TUI 한 쌍)이 여기 든다.
- 항상 켜 둘 봇은 자동 기동을 그대로 둔다(사용자 설정). 그 봇들은 지금처럼 restore가 건드리지 않는다.
- 스레드 세션 창은 하네스가 관리한다(폴더 봇은 `<폴더>/.discord-state/threads.json`, 다음 디스코드 메시지 때 이전 대화로 다시 연다). restore는 스레드 창을 만들지 않는다.

## 추가하는 것
1. **꺼져 있는 봇 찾기**: (A) 사이드카 중 그 이름의 tmux 세션이 없는 것 + (B) tmux 세션을 띄우는 구동 유닛 중 자동 기동이 꺼져 있고 그 세션이 없는 것. 세션↔유닛 대응과 브리지 판정은 기존 `internal/wiring`(폴더 봇 plist, 브리지 루트의 `.env*`·데몬/TUI 유닛)을 쓴다. 브리지 봇은 같은 env를 쓰는 데몬 유닛을 짝으로 묶어 한 줄로 보인다.
2. **체크리스트에 "꺼져 있는 봇" 묶음**: 기존 복원 항목 아래에 봇 줄(세션 이름·엔진)을 더한다. 기본 체크는 지난번 선택(없으면 전부 해제). 선택은 `<상태폴더>/restore-bots.json`에 기억한다.
3. **띄우기**: (A)는 `tmux new-session -d -s <세션> <사이드카 내용>`. (B)는 유닛을 기동한다 — macOS `launchctl kickstart gui/<uid>/<라벨>`, 리눅스 `systemctl --user start <유닛>`. 브리지 봇은 데몬 유닛을 먼저(이미 돌고 있으면 생략), 그다음 TUI 유닛. 세션이 이미 있으면 건너뛴다. 실패는 봇마다 한 줄로 보고하고 나머지는 계속한다.
4. **봇 관할 보호**: 꺼져 있는 봇으로 잡힌 세션의 죽은 레코드(봇 메인 pane·스레드 창)는 구동 유닛 관할과 똑같이 일반 복원 대상에서 뺀다(건너뜀 사유에 "봇 관할 — 체크리스트의 봇 묶음에서 띄움"). 일반 복원이 봇 세션에 채널 플래그 없는 창을 만드는 사고(2026-09-03)를 막는다.
5. **스크립트용**: `agentlayer restore --bots <세션,세션>`(그 봇만 띄움, 체크리스트 없이)와 `--no-bots`(봇 묶음 숨김). `--yes`는 봇을 띄우지 않는다(예전과 같은 결과). `--dry-run`은 "띄울 봇" 목록과 방법(사이드카/유닛)을 보여 주기만 한다.

## 범위 밖
- 자동 기동을 켜고 끄는 일(각 하네스 설정의 몫 — folder-bot `autostart`, 브리지 plist의 `RunAtLoad`).
- 스레드 창 되살리기, 봇 끄기.
