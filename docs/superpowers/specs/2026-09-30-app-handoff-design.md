# 데스크톱 앱 간 넘기기(handoff) 설계 — 한 장

작성 2026-09-30. 상태: **초안, 사용자 확정 전**. 확정 전에는 어떤 세션에도 구현을 지시하지 않는다.

## 메인 시나리오(이것만 된다면 성공)
1. Claude Code(데스크톱 앱 화면)에서 일하다 이미지가 필요 → 코덱스 앱 세션에 "이미지 만들어 줘" 요청 → 코덱스가 만들고 결과(파일 경로)를 Claude에 회신 → Claude가 이어서 작업.
2. Claude에서 헤르메스(VPS)로 헤르메스 밖의 스킬·파일을 보냄.

관제탑(웹)은 메인이 아니다. 필요해지면 그다음.

## 노드와 주소 (기존 것 재활용)
| 노드 | 주소 | 받기 | 보내기 | 상태 |
|---|---|---|---|---|
| Claude | tmux 세션명 (`agentlayer-dev`) | 채널 수신함 (`send`가 넣음) | `agentlayer send <주소>` | 훅 |
| 코덱스(앱) | 코덱스 세션 ID (UUID) | `codex queue --thread <ID>` (실측 됨) | 앱 안에서 셸 `agentlayer send <주소>` (실측 됨) | 없음(훅·tmux 없음) → "알 수 없음" |
| 디스코드 | 봇 세션(folder-bot) | 플러그인 채널 | 봇이 `send` | 훅 |
| 헤르메스 | 원격 이름 (`remotes/<이름>.json`) | 원격 어댑터 Dispatch/Answer(파일 첨부 있음) | 편지 회신 | Poll |

## 확정된 제약(2026-09-30 실기)
- **앱에서 새로 연 Claude 세션은 아무것도 못 받는다.** 앱이 `--channels`·개발 채널 플래그를 넘기지 않고(SDK stream-json 기동), 세션 간 메시지도 앱 화면에 나타나지 않는다. 소켓 직접 쓰기는 본문 형식이 문서에 없어 보류.
- 따라서 **Claude 노드는 터미널(tmux)에서 띄운 세션을 앱이 리모트 컨트롤로 비추는 것**이다. 사용자가 실제로 쓰는 방식("CLI에서 치면 앱도 같이 움직임")과 같다.
- 코덱스 앱은 CLI와 세션이 따로다. 앱 세션 ID가 주소이며 상태는 못 본다.

## 새로 만들 것(최소)
- A. `send <코덱스 세션 ID>`: 상태 기록 없이 UUID면 큐 직송, 실패 시 오류(폴백 없음). ← 클라우드 세션 진행 중(브랜치 `desktop-sessions`).
- B. 코덱스 앱 폴더 `AGENTS.md` 지침 한 블록: "요청 메시지의 회신 주소(`reply-to: <세션명>`)로 `agentlayer send`하라". 코덱스는 `send`를 셸로 치므로 코드 변경 없음.
- C. Claude 쪽 스킬/지침 한 줄: 코덱스에 넘길 때 메시지 머리에 `reply-to: <자기 tmux 세션명>`을 붙인다. (agentlayer `send`가 자동으로 붙이는 방식도 가능 — 결정 3)
- D. 헤르메스: 업무(task) 없이 보내는 `send <원격> [--file <경로>...]`. 어댑터의 업로드 기능은 있으나 지금 `send <원격>`은 AI 회사 업무 등록을 요구한다. 시청자는 대부분 로컬만 있으므로 시연에서는 "VPS가 있으면" 절.

## 이번에 안 하는 것
AI 회사(업무 보드·총괄), browser pick, worktree, 웹 관제탑(후순위), 앱에서 새로 연 Claude 세션 수신, 코덱스 앱 상태 표시, agy(비대화형 호출로만, 시연 제외 가능).

## 시연 흐름(초안)
앱의 Claude 화면에서 "썸네일 이미지 필요, 코덱스에 시켜" → Claude가 `send <코덱스ID> "reply-to: agentlayer-dev … 이미지 생성 요청"` → 코덱스 앱이 생성 → `agentlayer send agentlayer-dev "완료: /경로/x.png"` → Claude 화면에 채널로 도착 → Claude가 파일을 열어 이어감. (헤르메스 절: Claude가 `send hermes --file ~/.claude/skills/x/` → VPS에서 확인.)

## 사용자 결정 대기
1. Claude 노드 전제(터미널 세션 + 앱 미러)로 고정해도 되는가.
2. 회신 주소를 사람이 쓰게 할지(C를 지침으로), `send`가 자동으로 붙일지(agentlayer 코드 수정).
3. 헤르메스 D의 범위: 파일 전송까지 이번에 만들지, 텍스트만 먼저인지. 시연에서 보낼 실물(스킬 폴더?)은 무엇인지.
4. 클라우드 세션에 A 다음으로 무엇을 맡길지(B·C는 지침이라 맥에서 5분, D는 코드).
